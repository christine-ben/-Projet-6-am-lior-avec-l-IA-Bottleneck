# Fiche pour l'équipe : comment lire la liste des prix à vérifier

## À quoi sert cette liste ?

Elle montre les produits du catalogue dont le prix ou le stock paraît bizarre. Elle ne dit pas "voici les erreurs", elle dit "regardez ces produits en premier".

## Comment la lire ?

Chaque ligne est un produit. La colonne "raison" explique pourquoi il est signalé.

| Raison                        | Ce que ça veut dire                                | Quoi faire                                                                 |
| ----------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------- |
| Marge négative                | Le produit est vendu moins cher qu'il a été acheté | Vérifier le prix de vente et le prix d'achat, corriger si c'est une erreur |
| Ventes négatives              | Le nombre de ventes est négatif, c'est impossible  | Corriger la donnée                                                         |
| Prix élevé mais marge normale | Un produit cher dont la marge est normale          | Le plus souvent, c'est un vrai grand vin : on garde                        |
| Stock très élevé              | Beaucoup de bouteilles en réserve                  | Vérifier si c'est voulu                                                    |
| Aucune vente                  | Le produit ne se vend pas                          | Vérifier s'il est encore bien affiché sur le site                          |
| Profil inhabituel             | Aucune règle simple ne l'explique                  | Regarder le produit à la main                                              |

## À retenir

1. Un prix signalé n'est pas forcément une erreur.
2. Avant de corriger un prix, regarder la marge et le type de vin.
3. Aucun produit n'a été supprimé : c'est à vous de décider.

## Un produit à regarder en priorité

Le vin "Pierre Jean Villa Condrieu Jardin Suspendu 2018" apparaît sous 5 numéros avec les mêmes ventes négatives : c'est peut-être un doublon.

## Accessibilité

Cette fiche est écrite pour être lue par tous, y compris les collaborateurs en situation de handicap :

- phrases courtes et mots simples,
- titres clairs pour s'y retrouver (et pour un lecteur d'écran),
- police lisible et contraste fort,
- aucune information donnée par la couleur seule,
- chaque capture est accompagnée d'une phrase qui la décrit.
